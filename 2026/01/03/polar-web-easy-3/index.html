命运石之门

考查点：

访问链接，是一个登录界面，需要输入登录密码和验证码，但验证码显示不出来

查看网页源码，在注释中有提示：5pyJ5pe25YCZ77yM6aqM6K+B56CB5piv5ZCm5aW95L2/5LiN6YeN6KaB

一看就像 base64，解密

没其他线索，扫描一下目录看看，结果发现有个 password.txt，可以推断是要爆破

访问该路径果然得到一系列字符串，应该就是密码

既然有了密码字典，我们现在要考虑的就是验证码了，由于验证码图片显示不出来，验证码常常是四位数字或字母数字组合，我们可据此创造一个字典，配合密码字典进行爆破

（尝试后发现先爆破密码，然后再爆破验证码会快一点）

爆破出密码 hunangleiSAMA0712 后我们可以看到回显是：验证码错误！，这就说明我们爆破的密码对了，接着我们爆破验证码

爆破出验证码为 0000 时页面跳转，应该是成功了

我们进行登录进入下一步，发现又需要验证密码，再次进行爆破即可

获得密码 huan9le1Sam0，输入即可得到 flag

俄罗斯方块

考查点：js小游戏

访问链接，一看是小游戏，立马就想到是 js

查看 js 源码发现有乱码，用 burp 抓包看就行，在源码中我们发现当我们输入的信息中有<script> 标签时会进行跳转，此页面极有可能是 flag

尝试输入 <script>，发现果然弹出了 flag

其实直接访问 get_squirrt1e.php 也可以

代码审计easy

考查点：php代码审计、目录遍历

访问链接，有两个按钮：题在这哦、测试界面，这个会有用吗

先查看第一个发现是 vulnerable.php 源码

分析源码可知，此为一文件查看器，从 GET 参数 page 中获取文件名，然后尝试在 pages/ 目录下读取对应的文件，并将其内容以 HTML 转义的形式显示出来

源码中使用正则表达式检查 $page 是否包含 http:// 或 https://

还有，虽然代码尝试将文件限制在 pages/ 目录下，但是当文件不在 pages/ 目录下时，它又尝试直接使用 $page 作为路径，这也就意味着存在目录遍历

先别急，我们再看看第二个按钮是什么，点击后跳转至 /vulnerable.php，显示了一段源码，与上述并不同，我们应该是要在此页面传入 page 参数

尝试目录遍历：../../../etc/passwd，发现成功读取，确认存在目录遍历

接下来就是不断尝试访问 flag.php 或者 flag.txt，最终发现 ../flag.txt 成功读取

VIP

考查点：html前端绕过

访问链接，有一个 vip 按钮，flag 应该是点击后会回显，但点击按钮没反应，查看网页源码也没东西

用 burp 抓点击按钮的包发现有个 vipStatus 参数，其值为 no

我们将其改为 yes 重发就可以获得 flag
