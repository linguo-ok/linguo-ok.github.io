考查点：命令执行rce

此题是一道命令执行 rce 题，题目给出了可用命令：ls、pwd、whoami、date、echo、base64、sh，同时过滤了很多危险函数、特殊字符、文件读取函数，限制非常多

尝试 ls / 发现能够成功读取

但是我们需要使用白名单中命令，没有 cat 这些读取命令，提示说可以使用 allow:命令名 添加命令，尝试后发现虽然添加到了白名单但是提示保存失败，还是使用不了

继续尝试，输入 flag 发现过滤了一些目录

尝试 **echo ``**，发现过滤了一些字符

但是其中并没有过滤管道符 |，既如此我们就可以用管道符去拼接命令了

观察题目所给白名单，我们看到有 base64、sh 可用，那么我们的思路就可以是将命令编码，先用 echo 进行输出，通过管道符传给 base64 进行解密，然后通过 sh 执行

先用 ls / 进行尝试，其 base64 加密为：bHMgLw==，发现执行成功

如此，我们就可以通过这个思路去绕过读取了，cat /flag.php 加密：Y2F0IC9mbGFnLnBocA==

uii

考查点：php代码审计、双重URL编码绕过

访问链接，需要我们回答图中咖啡种类

看看网页源码，发现是：拿铁

输入后跳转，得到源码

分析一下，需要我们以 GET 方式输入 uii，并且值不能是 Yzz，接着需要输入的值在 urldecode 后的值是 Yzz

我们要知道的是当浏览器请求一个 URL 时，参数会被 URL 编码，PHP在填充 $_GET 时，会自动进行一次 URL 解码，当我们传入 Yzz，PHP 得到的就是 Yzz；当我们传入 Yzz URL 编码后的值，浏览器自动解码后为 Yzz。这就会触发第一段代码的条件，结合后面第二个条件，在判断前会进行一次 URL 解密，于是我们可以通过双重编码进行绕过

注：此题有些怪，直接传入 Yzz，%59%7A%7A 可以直接通过
