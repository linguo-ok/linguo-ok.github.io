接着判断 $a[0] 是否等于字符串 www.polarctf.com

注意：这里比较的是 $a 的第一个字符，而不是整个字符串。$a[0] 是一个字符，而 www.polarctf.com 是一个字符串，在比较时，由于PHP的类型转换，字符串 www.polarctf.com 会被转换为布尔值（非空字符串为true），但这里是比较运算符==，所以会进行类型转换。

在 php 中比较一个字符和字符串是不行的，这样比较时，字符会被当作字符串处理。但这里 $a[0] 是一个字符，而 www.polarctf.com 是一个字符串，它们不会相等，因为长度不同。但PHP的==比较会进行类型转换。我们来看一个例子：'w' == 'www.polarctf.com'，在PHP中，这会是false，因为字符串内容不同。但注意：如果 $a[0] 是字符串类型，长度为1，而右侧是字符串，所以比较的是两个字符串是否相等。显然不相等。

此时，我们需要注意到前面有 @parse_str($id)，我们可以利用它来覆盖变量 $a。如果我们通过 id 参数传递一个字符串，使得解析后变量 $a 被覆盖，那么 $a[0] 就可能改变。我们可以提高参数 id 覆盖 $a，使其变成一个数组，其第一个元素为 www.polarctf.com，这样我们就能够绕过这个判断了

分析源码，我们需要以 GET 方式输入一个参数 a，输入后会经过 is_numeric() 函数我们需要使其判断结果为 False；然后才能到 preg_match() 判断，此处过滤了 flag、system、php，我们需要使 preg_match() 匹配失败即可利用 eval() 函数进行命令执行

is_numeric()：用于检测字符串是否只由数字字符组成。它返回一个布尔值，如果字符串只包含数字字符，则返回 True，否则返回 False

综合分析，我们只需输入不为纯数字的字符串，然后绕过匹配检测（通配符绕过）就能够进行命令执行了

要注意的是 eval() 函数不能直接执行命令，它是代码执行函数，需要其他命令执行函数配合，比如：exec、shell_exec()、system()、passthru()、反引号、popen()/proc_open()、pcntl_exec()

PHP中常见的命令执行函数与代码执行函数_命令执行类似eval的有那些函数-CSDN博客

这里需要注意的是，eval() 函数是用于执行字符串中的PHP代码，当eval执行时，它会将字符串作为PHP代码来执行，并返回执行结果（如果有的话）。eval() 只是执行了这段代码，不会自动输出返回值

此处 shell_exec() 命令执行返回的结果字符串被 eval() 函数接收了，但如果我们没有对其作任何赋值或输出操作，那么其结果是不会显示在页面上的

passthru()：执行命令并将原始输出直接输出到标准输出，也就是说它直接将外部命令的输出发送到浏览器，而不需要通过 echo 或 return 来显示结果

反引号操作符在PHP中的行为与 shell_exec() 函数完全相同

这里需要注意 exec() 与 shell_exec() 的区别

exec()：用于在PHP中执行外部程序或命令，它可以执行命令行指令，并返回最后一行输出结果，exec()不会直接输出结果，而是将结果存储在一个数组中

此处除了像上面将命令执行结果存入数组，然后使用 print_r() 函数输出外，还有以下几种方法

1、用 implode 拼接输出

implode()：用于将数组元素连接成一个字符串

2、使用超全局变量 $_，$_ 是PHP预定义数组

3、循环遍历输出
