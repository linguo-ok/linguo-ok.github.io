PHP中常见的命令执行函数与代码执行函数_命令执行类似eval的有那些函数-CSDN博客

passthru()：执行命令并将原始输出直接输出到标准输出，也就是说它直接将外部命令的输出发送到浏览器，而不需要通过 echo 或 return 来显示结果

exec()：用于在PHP中执行外部程序或命令，它可以执行命令行指令，并返回最后一行输出结果，exec()不会直接输出结果，而是将结果存储在一个数组中
